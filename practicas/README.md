# Practicas y Entregas

Esta carpeta contiene los archivos de entrega de los participantes del curso.

Cada participante debe crear una subcarpeta con su nombre y colocar:
- Mapa de afectacion preliminar (.qgz, .png, .pdf)
- Nota periodistica georreferenciada (.docx, .pdf)
- Hilo informativo simulado (.docx, .pdf, .png)
- Autoevaluacion reflexiva (.docx, .pdf)
- Archivos adicionales (shapefiles, geojson, csv)
